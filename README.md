# Chaewony Labs

Independent developer building game addons, software tools, and whatever else seems useful.

Most of my projects start the same way: I want something, it doesn't exist, or the existing options don't quite do what I need — so I end up building it myself.

I care more about whether something is actually useful than making it complicated for the sake of it.

---

## What I Build

- Game addons
- Utility tools
- UI / UX tools
- Market and data tracking tools
- Small automation tools
- Experimental software projects

Some projects are released publicly, while others stay private depending on what they were made for.

---

## Development

My current interests include:

- Lua
- Game addon development
- UI / UX
- Data tracking
- Tooling and automation
- Small desktop and web utilities

I like keeping projects focused, practical, and easy to use.

---

## Development Philosophy

If I release something publicly, I want the useful parts of it to actually be available to everyone.

I don't like locking essential functionality behind paid tiers just to create a reason to upgrade.

I'd rather build something useful, keep improving it, and let people support the project if they genuinely want to.
